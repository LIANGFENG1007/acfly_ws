桌面原始文件不变。原始文件的 world 名称 lio_world 改为 arena_20x20；

## 坐标与参数

- 世界有效地板：X/Y ∈ [0,20]，外墙在 -1 和 21。
- 起飞世界坐标 (1,1,0)，yaw=0，朝 +X；是俯视图左下角内侧，距地板两边各 1m。
- Point-LIO 起飞原点坐标系：X/Y ∈ [-1,19]。不能使用旧地图的 (-4,0) 出生点。
- 默认启用探索，视觉 SHM 接收与投放保持开启（用户明确要求）。没有目标时沿原逻辑达到 95% 覆盖后归航。
- 探索终点 SLAM (0,0)，对应世界 (1,1)；隧道入口 (2,0)、H (4,0) 为占位，两端隧道开关及终点降高关闭。
- 保留原巡航速度、加速度、3.6m/100°视野、0.5m/0.05m覆盖栅格、0.4m机体半径和1m边界内缩。
- 原起飞高度 1.2m 保留。地图含低于飞行高度的障碍，当前程序是既有二维投影避障及视野覆盖，不是三维全体素建图完成率。

## 启动

先正常退出旧 PX4/Gazebo 仿真，再在新终端运行（本次未代启动）：

```bash
cd ~/uav_sim_env/PX4-Autopilot && \
PX4_GZ_MODEL_POSE="1,1,0,0,0,0" \
PX4_GZ_WORLD=arena_20x20 \
make px4_sitl gz_x500_lidar_3d
```

沿用现有 MAVROS、Point-LIO 仿真启动流程。源码默认值已经修改，但已安装二进制要重新编译才会包含新默认值；
也可以直接给已有程序传本次配置（无需编译，且不要同时启动两套主控/探索节点）。
在加载原 ROS/workspace 环境后，分两个终端运行：

```bash
ros2 run exploration_planner exploration_planner_node --ros-args \
  --params-file ${ACFLY_WS}/tools/sim/profiles/arena_20x20.yaml
```

```bash
ros2 run fly_mission fly_mission_node --ros-args \
  --params-file ${ACFLY_WS}/tools/sim/profiles/arena_20x20.yaml
```

如果原来使用 competition_sim.launch.py 一次启动全套，替换为下面命令即可，不能再叠加上面的两个节点：

```bash
ros2 launch exploration_planner competition_sim.launch.py \
  param_file:=${ACFLY_WS}/tools/sim/profiles/arena_20x20.yaml \
  mission_param_file:=${ACFLY_WS}/tools/sim/profiles/arena_20x20.yaml
```

看到「完程度达标 → 归航」即可按用户计划结束本轮统计，返航时间不计入探索效率。
保持每次地图、起飞点、95%阈值、视野和仿真速度一致，比较探索开始到归航切换的时间。
