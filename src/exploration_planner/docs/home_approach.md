# 终点安全入口与直线斜降

终点接近采用与视觉投放相同的 `plan_drop_approach` 圆周入口搜索。终点是已知任务坐标，雷达直接对准终点，不带包裹偏移，不执行视觉取样或投放动作。

## 流程

1. 以终点为圆心、`HOME_STRAIGHT_APPROACH_M` 为半径寻找安全入口，当前默认 1 米。近侧入口和整条路线安全时直接接近；受阻时才比较圆周其他入口，按可达路程选择，不为更多净距绕到远侧。
2. 入口必须可到达，入口到终点的完整下降直线必须避开所有已知障碍。计入机体半径、原规划余量和入口到点容差。最终位置只进入外层余量时，沿用视觉目标的渐变余量规则，仍保留机体半径、障碍拟合轮廓和执行余量。
3. 终点没有包裹朝向约束：在整条路线安全的前提下，将绕障后的最后一段与下降段对齐，选择该路点朝终点方向的最近圆周入口。不能保留一个偏离最终直线的圆周采样点，导致下降前再转一次弯。
4. 中间绕障路点通过局部 Bézier 圆角连接，曲线及其采样后的每条线段均检查实体障碍和规划边界。飞机连续跟随曲线切线前进，XY 速度独立纠偏；不逐个路点减速到零。沿途根据曲率提前限速，在入口处保持下降段的接近速度。只有无法安全圆角的狭窄段保留原低速逐段跟踪，不能为图形平滑切入障碍。
5. 曲线通过后保持同一条参考路线，只在剩余路径真实失效时重算。进度按实际位移有界推进，不跳到附近的后续航段。机头随曲线切线变化，实际 yaw 在进入终点 1 米范围、已走到核准入口末段且实际下降线安全时才锁定，随后直线前进并降到 `CORRIDOR_FLIGHT_Z`。已在入口圆内且整条下降线可用时就地开始，不为凑一米倒退。
6. 设定边界表示墙的位置。按当前归航任务要求，路线仍按配置范围规划/验收，但执行有效归航路线时关闭由这条设定墙线触发的速度保护：漂移或短期刹停投影越线不会把 XY 速度清零，继续沿路线并纠偏。点云检测到的实体障碍仍参与短程速度/刹停检查。该执行例外不用于无有效路线、普通探索、视觉投放接近或走廊控制。
7. 同视觉目标已核准的下降动作，开始后不因障碍拟合变化重选入口、绕路或触发通用避障悬停。XY/yaw 反馈、速度/加速度限幅、定位有效期及任务身份检查继续执行。
8. XY 首次到终点即可交给走廊控制器，立即转向并继续降高；不等待水平速度归零。航向和高度满足原走廊要求后再进入口、找门、穿门、前往 H。

## 参数

- `HOME_STRAIGHT_APPROACH_M` / `home_straight_approach_m`：安全入口圆半径，默认 1.00 米。保留旧参数名以兼容启动命令；设为 0 使用普通必达点避障，关闭入口斜降。
- `HOME_SLOW_RADIUS_M`：沿剩余路线接近入口时的减速范围；曲线跟踪从巡航速度连续过渡到 `HOME_APPROACH_V`，不在入口停车。`HOME_SLOW_V` 保留为无法安全圆角、使用逐段跟踪时的近端限速。
- `HOME_APPROACH_V`：入口到终点的水平速度上限。
- `CORRIDOR_LOWER_ENABLED`、`CORRIDOR_FLIGHT_Z`、`CORRIDOR_DESCEND_MPS`：沿用走廊降高开关、高度及下降限速。没有有效走廊任务或关闭降高时只执行 XY 终点接近。
- `HOME_GOAL_WALL_MARGIN`：终点到任务边界的允许距离。入口保留到点容差；不能把任务边界当成实体墙，也不能忽略点云中的实体障碍。

未找到可行入口时不启动下降，明确反馈 `home_no_safe_entry`，由原有安全脱困/保持逻辑处理。连续失败搜索限频；已采用路线失效则立即重算。

## 诊断与验证

新增诊断 `home_safe_entry_valid/x/y/reason`，并保留 `home_straight_approach`、`home_descent_started`。前者表示已承诺从入口到终点的直线动作。

`home_safe_entry_test` 覆盖无障碍近侧直达、左右镜像多障碍、完整下降包络、入口保持、提前锁航向/XY 门控、终点被占据、边界终点、关闭功能、已核准下降的持续执行、XY 到位但仍有速度/高度差时的走廊交接及新任务重置。

```bash
ctest --test-dir build/exploration_planner -R '^(home_safe_entry_test|visual_drop_node_test|exploration_corner_transition_test)$' --output-on-failure
```

几何核准依据当前二维点云地图，不包含未知障碍高度或真实涡流。开始下降后按已核准动作执行，后续新障碍不会触发此段的重新规划。
