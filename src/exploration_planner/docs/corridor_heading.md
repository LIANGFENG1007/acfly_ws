# 终点就近转正后穿通道

默认在到达终点、开始通道任务后的首个有效位姿上，从世界坐标系的 `0°、90°、180°、−90°` 中选择最小转角方向，所需转角不超过 45°。只选一次，随后转向、下降、进入口、对门中心、穿门和到 H 均保持所选航向。±180° 表示同一朝向。

`CORRIDOR_NEAREST_CARDINAL_YAW = true` 启用此行为，对应启动参数 `corridor_nearest_cardinal_yaw`。只有设为 false 时，才使用 `CORRIDOR_INITIAL_YAW_DEG` / `corridor_initial_yaw_deg` 指定的固定航向。原启动命令即可使用新的默认行为。

选角不会在定位抖动或数据断流恢复时重算；新任务清除上次选角和转向稳定计时。恰好等距的两个正方向按取整确定其中一个，并锁定。无有效定位、未收到入口/H 路线时不提前选角。

转向同时继续给 XY 定点纠偏速度，降高仍可并行；当前机头和高度都到位后，默认切换为真实的飞控 XYZ 位置和绝对 yaw 接口，再横移进入口，不要求飞机完全停稳。交接期间固定实际 XY，Z 从第一个位置帧开始保持设定的通道高度。详见 [通道位置控制](corridor_position_control.md)。

通道前进轴由入口→H 决定，机头朝向独立。位置参考使用世界坐标，不随机头旋转，因此允许侧飞或倒飞穿通道，不改变门中心、过门顺序和 H 点。显式关闭 `corridor_position_control` 时保留原速度接口。

终端首次选角时打印：`[走廊转正] 当前 ...° → 锁定 ...°，最短转角 ...°`。

`corridor_heading_test` 覆盖四向选择、跨 ±180°、等距分界、漂移/断流后保持选角、新任务重新选择、固定模式兼容、转向时 XY 纠偏及高度交接，以及四种朝向在两种通道方向下穿过相同的两扇门。`home_safe_entry_test` 覆盖节点层从终点下降交接到新航向的流程。
